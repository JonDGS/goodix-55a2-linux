# Contributing

Thank you for helping with Linux support for the Goodix `27c6:55a2` sensor.

## Before sharing data

Do **not** attach raw packet captures, sensor images, enrolled templates, driver dumps containing secrets, or any data that may identify a fingerprint owner. Open an issue describing the experiment and its metadata first; maintainers can determine whether a sanitized fixture is appropriate.

## Good contributions

- Reproducible observations from the target USB ID.
- Protocol notes tied to commands and evidence.
- Small tools with clear input/output contracts.
- Sanitized fixtures and tests.
- Improvements that make later `libfprint` review easier.

## Pull requests

Keep each pull request narrow. Explain the device and software environment, the exact experiment, expected versus observed behavior, and how the change was tested. Preserve attribution when adapting earlier research.

By contributing, you agree that your work may be distributed under this repository's MIT License.
